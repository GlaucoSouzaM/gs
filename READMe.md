# Sobre

Esta é a minha central integrada de conexões e portfólio profissional. Um espaço dinâmico projetado para concentrar minhas redes sociais, apresentar meus estudos em Ciência da Computação e outros. Expor projetos práticos desenvolvidos, um ambiente em que você possa conhecer mais de mim. Explore o ecossistema para conhecer mais das minhas criações.

## Tecnologias

*   **HTML5:** Estruturação semântica de todo o conteúdo e acessibilidade.
*   **CSS3:** Estilização moderna, uso de Flexbox/Grid para layout e criação de design responsivo.
*   **Design Responsivo:** Adaptado perfeitamente para visualização em smartphones, tablets e desktops.

## Aprendizados

*   **Semântica Web:** Melhoria na escrita de códigos HTML mais limpos e acessíveis para leitores de tela.
*   **Domínio de CSS:** Prática intensiva com posicionamento, alinhamento responsivo e estilização de componentes de interface (UI).
*   **Organização de Portfólio:** Entendimento de como apresentar informações profissionais de maneira direta e atraente para o mercado de tecnologia.
*   **Arquitetura de Projetos:** Planejamento de layout focado na experiência do usuário (UX).
